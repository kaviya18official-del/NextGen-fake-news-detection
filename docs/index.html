🤖 1. ML Patterns

TF-IDF Logistic Regression & Linear SVM evaluating lexical and stylistic patterns against known distributions.

🔍 2. Checkable Claims

Deterministic sentence segmentation isolating numbers, percentages, dates, and reporting assertions.

📰 3. Prior Fact-Checks

Google Fact Check Tools API query with schema validation, quota management, and status tracking.

⚖️ 4. Evidence Match

Lexical similarity (Jaccard + sequence alignment) classifying reviews as relevant, related, or rejected.

📋 5. Responsible Verdict

Strict assessment without collapsing distinct inquiries into an arbitrary or ungrounded truth score.
